# Baby Products
ระบบรวมล่าสุดมีสต๊อกแยกสี/ไซซ์ แผนที่สมัครใจ ตรวจสลิปซ้ำ ภาษี/เอกสารแบบตั้งค่าได้ และ TH/EN ดู [COMPLETE_COMMERCE_REPORT.md](COMPLETE_COMMERCE_REPORT.md) สำหรับวิธีใช้ การตั้งค่าที่ต้องใช้ข้อมูลจริง และผลทดสอบล่าสุด
ระบบร้านค้าแม่และเด็กสาธิต PHP 8.x + PDO MySQL สำหรับ XAMPP ไม่มี Framework

## ติดตั้ง

สถานะเครื่องนี้ ณ 9 พฤศจิกายน 2026: มีฐานข้อมูล 22 ตาราง 6 หมวดหมู่ สินค้า 24 รายการ บัญชี Admin 1 บัญชี ลูกค้าจำลอง 5 บัญชี และสมาชิกที่สมัครเพิ่ม เปิด GD แล้ว ไม่ต้องนำเข้า SQL หรือสร้าง Admin ซ้ำ ขั้นตอนติดตั้งด้านล่างใช้สำหรับเครื่องใหม่เท่านั้น

1. เปิด Apache และ MySQL ใน XAMPP Control Panel ต้องมี PHP extensions pdo_mysql, mbstring, fileinfo และ gd
2. โครงการอยู่ที่ C:\xampp\htdocs\babyproducts
3. เปิด http://localhost/phpmyadmin เลือกฐานข้อมูล babyproducts ที่ว่าง แล้วเลือก Import > เลือก database.sql > Character set utf-8 > Go ไฟล์นี้ไม่มี DROP TABLE แต่ถ้ามีตารางอยู่ต้องหยุดและสำรอง/ตรวจสอบก่อน ห้ามนำเข้าซ้ำ
4. เชื่อมต่อค่าเริ่มต้น 127.0.0.1, root, รหัสผ่านว่าง หากต่างออกไปให้ตั้ง environment DB_HOST, DB_NAME, DB_USER, DB_PASS สำหรับ Apache และ CLI อย่าเก็บรหัสผ่านใน Git
5. เปิด http://localhost/babyproducts/
6. สร้าง Admin ครั้งแรกด้วยตัวช่วย PowerShell ด้านล่าง ป้อนชื่อ อีเมล และรหัสผ่านเฉพาะของคุณ (12–72 ไบต์) รหัสผ่านซ่อนขณะพิมพ์ ส่งให้ PHP ทาง stdin และเก็บในฐานข้อมูลเป็น hash เท่านั้น ไม่ใส่รหัสผ่านใน command line หรือส่งในแชต เครื่องมือปฏิเสธเมื่อมี Admin แล้ว ไม่มีบัญชี Admin หรือรหัสผ่านสำเร็จรูปใน SQL
7. สมัครบัญชี Customer ผ่านหน้าเว็บ จากนั้นทดสอบตะกร้าและ COD

รันจาก PowerShell เพื่อเปิดตัวช่วยตั้งค่า Admin (RemoteSigned มีผลเฉพาะ process นี้ ไม่เปลี่ยนนโยบายถาวรของเครื่อง):

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File C:\xampp\htdocs\babyproducts\tools\setup_admin.ps1
```

เมื่อเห็น `Admin created.` ให้เข้าสู่ระบบที่ http://localhost/babyproducts/login.php และเปิดหลังร้านที่ http://localhost/babyproducts/admin/ หากเห็น `Invalid input` ให้รันตัวช่วยใหม่และตรวจรูปแบบอีเมลกับความยาวรหัสผ่าน

ยังใช้ `C:\xampp\php\php.exe tools\create_admin.php` ได้ แต่โหมดนี้จะแสดงรหัสผ่านขณะพิมพ์ จึงแนะนำตัวช่วย PowerShell

## การทำงาน

ดีไซน์ล่าสุด Modern Premium Baby Boutique: โทน Warm Ivory/Soft Cream/Dusty Rose ใช้ภาพห้องเด็กแสงธรรมชาติเป็น Hero ลดสัญลักษณ์และป้ายตกแต่ง หน้ารายการ รายละเอียด ตะกร้า เข้าสู่ระบบ และสมัครสมาชิกใช้ดีไซน์เดียวกัน ตะกร้าบนมือถือแสดงเป็นรายการอ่านง่าย ภาพใหม่ 1 Hero + 16 ภาพสินค้าเปลี่ยนฉากหลังตามหมวด เก็บภาพก่อนหน้าไว้ครบ โหลด CSS ผ่าน assets/css/premium.css แบบ version ตามเนื้อหา ดูรายละเอียดใน PREMIUM_DESIGN_REPORT.md และ prompt ใน tools/premium-image-manifest.json

ตรวจผ่าน Chrome emulation จริงที่ 1440/768/390 พิกเซลครบ 6 หน้า พร้อมแท็บ/quick view/เพิ่มตะกร้า และ integration 64 ข้อบนฐานข้อมูลทดสอบแยก ไม่ต้องนำเข้าฐานข้อมูลหรือสร้าง Admin ใหม่

ภาพสินค้าล่าสุด 9 พฤศจิกายน 2026: ใช้ภาพ AI แนวถ่ายสตูดิโอเฉพาะ SKU ครบ 24 รายการใน `uploads/products/` เป็น WebP 1200 × 1200 พร้อม 800/480 พิกเซล เฉลี่ยไฟล์หลักประมาณ 84 KB รูปหน้าแรก หมวดหมู่ รายการ รายละเอียด ตะกร้า และหน้าดูแบบย่อเชื่อมภาพแล้ว มีคำกำกับภาพจำลองเพื่อไม่อ้างว่าเป็นภาพสินค้าจริง รายละเอียดไฟล์ ภาพที่ยังขาด prompt และข้อมูลสำรองอยู่ใน PRODUCT_IMAGE_REPORT.md

หน้าร้านมีแบนเนอร์สลับ 3 ชุด แท็บสินค้าแนะนำ/มาใหม่ การ์ดหมวดหมู่แบบโต้ตอบ ดูสินค้าแบบย่อ และปุ่ม + เพิ่มตะกร้าโดยไม่เปลี่ยนหน้า พร้อมข้อความแจ้งผลและจำนวนตะกร้า เมนูติดขอบบนและปุ่มกลับขึ้นด้านบน การเคลื่อนไหวลดลงตามการตั้งค่าของอุปกรณ์ ใช้ไฟล์ assets/css/storefront.css ร่วมกับ CSS เดิม โดย URL ไฟล์ CSS/JS เปลี่ยนตามเนื้อหาเพื่อป้องกันแคชเก่า


ข้อมูลในเครื่องล่าสุด: มีสินค้า 24 รายการ หลังเพิ่มชุดตัวอย่าง `DEMO-019` ถึง `DEMO-024` อีก 6 รายการ หมวดละ 1 รายการ ชุดนี้ใช้ภาพ SVG ตัวแทนหมวดหมู่ พร้อมคำอธิบายว่าเป็นสินค้าจำลอง เพิ่มในเครื่องใหม่ได้ด้วย `C:\xampp\php\php.exe tools\seed_extra_products.php` โดยต้องนำเข้าฐานข้อมูลเริ่มต้นก่อน เครื่องมือข้ามรหัสสินค้าที่มีอยู่แล้วและไม่เขียนทับข้อมูลเดิม

- ฐานข้อมูลเริ่มต้นมี 6 หมวดหมู่ 18 สินค้า เพิ่มชุดตัวอย่างอีก 6 รายการด้วย tools/seed_extra_products.php รวม 24 รายการ พร้อม SVG ต้นฉบับที่วาดขึ้นเพื่อโครงการ ไม่อ้างว่าเป็นสินค้าที่ขายจริง
- ค้นหา กรองราคา/หมวดหมู่ เรียงลำดับ แบ่งหน้า สมาชิก เปลี่ยนรหัสผ่าน ที่อยู่ และความยินยอม
- ตะกร้า Session; COD ใช้ Transaction และ SELECT FOR UPDATE; คำนวณจำนวนเงินเป็นสตางค์; snapshot ราคาสินค้า; token unique ป้องกันรายการซ้ำ
- ค่าจัดส่ง 50 บาท ฟรีเมื่อยอดสินค้าครบ 1,000 บาท
- สถานะ pending > confirmed > preparing > shipped > delivered; ยกเลิกได้ก่อน shipped คืนสต็อกใน Transaction ครั้งเดียว ไม่มีการหักสต็อกเมื่อเปลี่ยนสถานะ
- สถานะรับเงินแยกจากจัดส่ง ผู้ดูแลยืนยันได้รับเงินจริงได้หลัง delivered เท่านั้น
- รายงานยอดขายเฉพาะ delivered รวมค่าจัดส่ง อิงวันที่สั่งซื้อ รายงานสินค้าขายดีไม่รวมค่าจัดส่ง
- Admin ปิดสินค้า/หมวดหมู่แทนลบ สมาชิก Customer ระงับได้ ปิดกั้น session ของบัญชีที่ถูกระงับในคำขอถัดไป
- อัปโหลด JPEG/PNG/WebP ไม่เกิน 5MB และ 4096x4096 ตรวจ MIME/โครงสร้างและ decode/encode ใหม่เป็น WebP 1200×1200 พร้อมภาพย่อ 800/480 พิกเซล ชื่อสุ่มใน uploads/products/ จัดเต็มภาพแบบ contain ไม่รองรับ SVG จากผู้ใช้ ต้องเปิดใช้ .htaccess/AllowOverride ใน Apache หน้า Admin > สินค้า > แก้ไข มีปุ่มเปลี่ยนเฉพาะภาพโดยไม่แก้ชื่อราคาและสต็อก
- PDPA: บันทึกเวอร์ชัน/เวลาความยินยอม ถอนใน profile ส่งคำขอเข้าถึง/ลบได้ ผู้ดูแลต้องดำเนินการด้วยตนเองก่อนปิดคำขอ

## ตรวจสอบก่อนเปิดใช้จริง
กำหนดช่องทางติดต่อ ผู้ควบคุมข้อมูล ฐานการประมวลผล ระยะเวลาเก็บรักษาที่อนุมัติและงานลบตามกำหนด ผู้ให้บริการขนส่ง เงื่อนไขคืนสินค้า และตรวจนโยบายกับผู้รับผิดชอบ ใช้ HTTPS และบัญชี MySQL เฉพาะที่จำกัดสิทธิ์ สำรองข้อมูล ทดสอบกู้คืน กำหนดการติดตามข้อผิดพลาด ไม่ใช้ root/รหัสผ่านว่างใน production
ฟอนต์ Prompt โหลดจาก Google Fonts พร้อม Tahoma สำรอง หากต้องการไม่เรียกภายนอกให้ติดตั้งฟอนต์ในเครื่อง
